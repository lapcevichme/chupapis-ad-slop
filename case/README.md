# Исходные материалы кейса 1

Получены от пользователя, разобраны 31 октября 2026 года. Оригиналы сохраняем без правок.

- [Кейс1/task.md](Кейс1/task.md) — подробное задание и FAQ, основной источник требований.
- [Кейс1/mock-data.md](Кейс1/mock-data.md) — описание контрактов и синтетических данных.
- [Кейс1/mocks/](Кейс1/mocks/) — 11 фактически выданных JSON-файлов.
- Word-файл в этой же папке — тизеры трёх кейсов; подробное задание имеет приоритет.

`task.md`, `mock-data.md` и все 11 JSON были побайтово сверены с прежними копиями из `docs/oragnisators/`. Дубли удалены после обновления ссылок; здесь остаётся единственный комплект исходников.

Не дописывать недостающие файлы в оригинальный `mocks/`: восстановленные данные хранятся отдельно в `backend/seed/`, с указанием происхождения.
