# Новая рабочая панель

31 октября 2026. **Выбраны стиль «Брифа» и ассистент справа из «Студии». Новая панель внедрена в React.** Ниже сохранены исходные альтернативы. Макеты используют синтетический пример из демо-диалога. Сохранение, генерация и модерация здесь не вызывают API.

- [Студия](directions/studio.html) — креативы на большом холсте, параметры по вкладкам, контекстный ассистент. Лучше для нескольких форматов.
- [Бриф](directions/brief.html) — результат появляется внутри разговора; «Проверить кампанию» открывает отдельную проверку. Рекомендуемая основа по ясности сквозного пути.
- [Привычный чат](directions/canon.html) — нейтральная запасная композиция, не основное направление.

Для просмотра из корня репозитория: `python3 -m http.server 5174 --bind 127.0.0.1 --directory design/directions`, затем открыть `http://127.0.0.1:5174/studio.html` или `brief.html`. Макеты автономны, для шрифтов используется Google Fonts.

## Проверка

В [captures/](captures/) — снимки 1440×900, 1366×768 и 390×844; [verification.json](captures/verification.json) содержит размеры и проверку отсутствия горизонтального переполнения. На телефоне у «Студии» работают CSS-переключатели зон; у «Брифа» — переходы к кампании и превью. При прокрутке ввод остаётся доступен.

Независимое визуальное ревью: направления готовы к показу для выбора. Детектор после исправлений: у «Брифа» замечаний нет, у «Студии» два предупреждения о padding вкладок/предупреждения, визуально не подтверждённые ревьюером. Это не проверка полной функциональности приложения.

При реализации «Студии» обязательная сводка перед записью должна показывать расширение OR-аудитории: в компактном диалоге предупреждение может уйти ниже видимой области. Для обоих направлений нужны реальные состояния ошибок, повторов, длинных диалогов, мобильной клавиатуры и отдельного подтверждения модерации.

Бриф — [brief.md](brief.md), источники — [references/README.md](references/README.md), продукт — [PRODUCT.md](../docs/PRODUCT.md), единый журнал решений — [DECISIONS.md](../docs/DECISIONS.md).

Снимки страницы входа — `captures/entry-*.jpg`. Сфера на ней — Созвездие из голосового режима, в обеих темах; сам голосовой режим в светлой теме остаётся с Перламутром. Первая версия с фото есть в истории git, коммит `bf1f619`.

Работающий интерфейс: `frontend/src/workspace.css`, запуск `cd frontend && npm run dev`. Снимки `captures/live-*.jpg` относятся к настоящему API и отдельной БД моков, остальные — к исходным макетам. Система и Motion — [docs/DESIGN.md](../docs/DESIGN.md).
