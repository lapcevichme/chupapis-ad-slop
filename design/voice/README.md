# Голосовой режим

31 октября 2026. **Концепт на выбор; в продукте ещё нет.** [Прототип](prototype.html) открывается двойным кликом. В правом нижнем углу панель: два варианта сферы, все состояния и сценарий с реальными паузами из замера. Данные синтетические, звука и API нет, амплитуда сферы имитируется.

Референсы Refero и Mobbin в этой сессии не подключены; паттерн взят из общеизвестного поведения голосовых режимов (сфера на весь экран, ход по нажатию), исследования по галереям не было.

Снимки: [Перламутр](../captures/voice-pearl-mobile.png), [Созвездие](../captures/voice-stars-mobile.png), [ПК](../captures/voice-pearl-desktop.png).

## Сценарий

| Состояние | Экран | Звук | Событие-источник |
|---|---|---|---|
| Приветствие | Сфера на весь экран | заготовка | открытие режима |
| Слушаю | Сфера реагирует на микрофон, «Закончить» | — | нажатие |
| Думаю | Распознанная фраза, шаги, сфера собирается в пояса | заготовка «Секунду, смотрю» сразу после нажатия | `step`, `draft_updated` |
| Говорю | Текст реплики, «Перебить» | `POST /speech/synthesis` | `message_delta` |
| Анкета | Сфера уходит в плашку, снизу лист | короткая заготовка | `suggestions` с `group` |
| Макет | На весь экран, вкладки форматов, «Черновик: ещё не сохранён» | — | `draft_updated` |
| Карточка | Операции, предупреждение, кнопка | заготовка «Проверьте и подтвердите» | `confirmation_required` |
| На модерации | Сфера затихает, разговор завершается | короткая фраза | `campaign_updated`, `done` |

Сбои: нет микрофона → продолжить текстом; не распознано → повторить; нет озвучки → тот же ход текстом; агент не ответил → повторить через `/retry`, ничего не записано.

## Решения

- **Ход по нажатию, без авто-определения паузы.** Работает в шумном зале, микрофон закрыт на время озвучки, поэтому нет эха.
- **Сфера — один элемент.** В плашку уезжает она сама: переход показывает, что ассистент не исчез.
- **Запись только кнопкой.** На открытой карточке кнопка микрофона называется «Сказать правку», потому что сервер трактует сообщение при открытой карточке как отказ с правкой (`docs/contracts/chat.md`). Сказанное «да, отправляй» запись не выполнит.
- **Заглушки — заранее записанные файлы.** Первый звук не зависит от агента; на тяжёлых ходах он молчит 9–14 с.
- **Озвучиваем до двух предложений, не больше 300 символов.** Остальное на экране. Разбивка учитывает даты и сокращения.
- **Анкета без изменения контракта.** Группы в `suggest_options` уже есть; ответы уходят одним сообщением, как в `Suggestions.tsx`.
- **Режим — отдельный слой.** `features/voice/` со своими компонентами получает объект из `useChat`, использует ту же сессию и историю. В панели только кнопка входа, за флагом `VITE_VOICE_MODE`. Цвета берутся из токенов панели, кроме самой сферы.
- **Заготовки:** приветствие, «Секунду, смотрю», «Проверьте и подтвердите», «Повторите, пожалуйста» — mp3 в `public/`, генерируются один раз.

## Открытые вопросы

- Голос `sarah` женский, а агент пишет о себе в мужском роде («Понял», «Собрал»). Нужны безличные формулировки в промпте или мужской голос.
- Зрители по QR: лимит на озвучку и распознавание до демо; без него ручки открыты.
- Реальная амплитуда (`AnalyserNode`) и автовоспроизведение на iOS проверяются только на устройстве.
- Прототип не заменяет проверку превью: в продукте макет строится из JSON креатива, а не из этой заглушки.
