# Студия креативов

31.10 пользователь расширил задачу: яркий интерфейс, AI-макеты из слоёв, ручное редактирование, загрузка материалов и сравнение вариантов. Это развитие продукта сверх исходного обязательного MVP.

## Устройство

- Внутренний `StudioDocument` хранит текст, фигуры и изображения отдельными слоями: координаты, размер, поворот, прозрачность, порядок, видимость и блокировку. Это наша модель редактора, не официальный JSON банка.
- Выбор, перемещение, изменение размеров и свойств; добавление и удаление слоёв, дублирование, undo/redo. Сравнение показывает варианты рядом и выбирает вариант для дальнейшей работы; само по себе ничего в кампании не меняет.
- Черновики и варианты сохраняются локально с явным обозначением. По кнопке применения создаётся неизменяемая пара PNG + документ слоёв, затем обновляется банковский объект. После перезагрузки сцена восстанавливается по ссылке изображения. Публикация и модерация остаются прежними.
- Генерация возвращает редактируемые документы. Существующие баннеры импортируются из их JSON. Готовая фотография — один слой: её внутренние предметы нельзя честно обещать редактировать отдельно.
- SVG и фото декодируются и приводятся к PNG до загрузки; SVG не вставляется в DOM и не хранится как исполняемый документ. Загрузка использует действующую ручку медиа.

## Банковский экспорт

В §2.6–2.7 задания нет произвольных координат. Поэтому свободная композиция передаётся изображением; слои живут отдельно. Текстовые лимиты проверяются до экспорта, действия и ссылки сохраняются. Для PROMO банковские кнопки остаются самостоятельными рабочими компонентами под изображением; их свойства редактируемы, положение задаётся вертикальным стеком банка. Эта граница явно показывается в редакторе.

Сохранение ручной правки — явное действие менеджера; сервер кампаний проверяет роль, состояние и аудит. При изменении исходного объекта во время редактирования нужно сообщить о конфликте. Несохранённые объекты с временными ID можно редактировать и экспортировать, применение в кампанию доступно после их создания.

## Интерфейс

Полноэкранная студия: инструменты и слои слева, холст в центре, свойства справа, варианты снизу. Сравнение — отдельный режим того же пространства. Контролы раскрываются по выбору объекта; сложность Фигмы не переносим. На узкой ширине слои и свойства открываются по запросу.

Направление: насыщенный кобальт, контрастная типографика Onest, светлая рабочая поверхность и цветной холст. Цвет интерфейса независим от цвета рекламы. Основная последовательность: AI-варианты → выбор → ручная правка → просмотр → явное применение.

## Эксплуатация и границы

- Локально хранится до 12 вариантов; применённый документ и PNG — на сервере. Не обещаем общий командный список всех локальных вариантов. При новой серверной версии добавляется вариант «В кампании», старые локальные правки сохраняются.
- AI использует существующие `LLM_API_KEY`, `LLM_BASE_URL`, `DESIGN_MODEL`; новых секретов и миграций нет. Запрос предлагает три сцены, сохраняет точные тексты и их роли, размер/формат, доступные источники изображений и видимость оффера. Ошибка модели не меняет текущий макет. Локальные композиции запускаются отдельной кнопкой.
- Баннер компилируется в изображение без дублирующих нативных текстов/CTA; исходные actionType/link сохраняются, voiceOver собирается из видимого текста в пределах 200 символов. PROMO — изображение плюс до пяти нативных кнопок: подпись, цвета, размер, порядок, добавление/удаление. Новая кнопка получает `default`, существующая сохраняет действие и ссылки. Нативные кнопки общие для вариантов изображения, в undo/redo холста не входят.
- Перед применением клиент перечитывает исходный объект и сообщает о найденном изменении. Это проверка конфликта, не серверная блокировка: банковский PUT не имеет ETag/compare-and-swap.
- Экспорт браузерный, PNG 2×. Фото — до 20 МБ на входе, загружается сжатый PNG до 5 МБ. Неподдерживаемый декодером формат объясняется ошибкой. Внешние картинки требуют разрешённого CORS; при отказе нужно загрузить файл через студию.
- SVG очищается от скриптов, внешних ссылок и небезопасных узлов и переводится в растр. Фотография и загруженный SVG являются единым изображением; их внутренние предметы/контуры не становятся отдельными слоями. Фигуры и текст, созданные AI-дизайнером студии, остаются самостоятельными объектами.
- Роль и состояние не обходятся: модератор и кампания на модерации доступны для просмотра/PNG, применение недоступно. Несохранённый черновик можно править локально; применить можно после создания банковского объекта.

Проверки модели фронта: `node --experimental-strip-types --test frontend/tests/studio-model.test.ts` из корня. Результаты живых и браузерных прогонов — [STATUS.md](STATUS.md).


## Предметные слои и точечная правка, 1 ноября

`illustration` с внутренним symbol `coffee|card|travel|car` отображает готовый прозрачный PNG
из `frontend/public/studio/`. Это библиотека из четырёх изображений, а не генерация произвольного
нового предмета по каждому запросу. Предмет можно двигать, масштабировать, вращать, скрывать,
удалять, заменять другим символом или своей картинкой. Внутренние части одного PNG не отделяются.
Кофе и карта сгенерированы для студии; автомобиль и чемодан сделаны прозрачными на основе
сгенерированных командой иллюстраций страницы входа. Исходники в `public/entry` не менялись.

`POST /studio/generate` принимает `mode=variants|edit`, `selectedLayerIds`. Правка возвращает
один новый вариант, не изменяет оригинал. При выделении сервер проверяет полное равенство
невыделенных слоёв и фона; выделенный текст можно переписать. При генерации вариантов либо
правке без выделения все исходные тексты сохраняются дословно. Количество и id/role текстовых
слоёв сохраняются, произвольные URL изображений не принимаются. Иллюстрация выбирается
моделью из каталога, её цвета фиксированы. Это не редактирование области внутри фотографии.

Начальная генерация баннеров теперь по умолчанию использует `IMAGE_MODE=illustration`
с предметным 3D-промптом; при сбое провайдера остаётся прежний fallback на паттерн.
Её растровая картинка импортируется единым слоем; независимые предметы создаёт библиотека
или AI-дизайнер студии. Слои сохраняются серверным sidecar, в банк уходит PNG.
