| D12 | Требование кейса | Изображения — дополнительная функция; баннер без картинки остаётся валиден. AI-изображения людей не генерируем (§10.9). Внешние LLM разрешены на синтетике; возможность смены модели обязательна |
| D13 | Принято | Локальные небольшие смысловые коммиты по завершении проверенного блока, push только по прямому разрешению. Конкретные файлы в индексе, без чужих изменений и атрибуции ассистента |

D09 опирается на строгий текст задания и запись ответа ментора 31.10: озвученное предложение времени допустимо. Запись не отменяет обязанность подтверждать запись. Источник ответа — [прежние заметки](archive/checkpoint-notes-2026-10-31.md), а не независимо полученное разъяснение.

## Почему не принимаем решение «переписать всё» заранее

Пользователь разрешил глубокую переработку и не хочет копировать старый дизайн. При этом 44 существующих теста проходят; доменные схемы, эталоны и защищённое выполнение операций могут сэкономить время. Это основание сравнивать по слоям, а не доказательство качества всей системы. Решение о каждом переносе должно ссылаться на требование, проверку или конкретное преимущество шаблона.

## Что отменено как обязательное

Ранняя заявка `ours/CONCEPT.md`: создание сегментов, лимиты показов/частоты, пересечения кампаний, аналитика и юридические проверки не входят в обязательный MVP. Её проценты экономии и сроки — гипотезы. Палитра «Изумруд», шрифт и три колонки не фиксируют новый интерфейс. Утверждение старого AGENTS о неразрешённых вопросах chat API устарело: сам контракт помечен как принятый.
